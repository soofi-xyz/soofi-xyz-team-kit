# Historical agent material

This directory preserves specialists removed from the installed product roster
on 2026-09-30. Files here are reference material, not active agent definitions.
Cursor, Copilot and Codex receive only the definitions in the root `agents/`.

Use the product map in the root README for current assignments. Do not restore
an archived agent or follow its old product ownership implicitly. Supporting
skills remain available at their existing paths, including the self-contained
Oracle runtime. When explicitly using a historical procedure, execute the
relevant skill directly and resolve any retired handoffs against the current
catalog. Historical product requirements do not override current product scope.

To restore a specialist, first identify its canonical product and build or
configure role, update its instructions, add it to the catalog, regenerate the
agent copies, and validate the product map.
