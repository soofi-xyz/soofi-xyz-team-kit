# Console capability map

Use Chandelure to implement Console and Vivillon to build apps and configure existing
capabilities. Follow the [shared workflow](../../SKILL.md). These areas are a
starting inventory, not a fixed iteration count. Order dependencies and split
independently useful features further. Use at least four pieces for a full-product
build; narrow work selects only relevant pieces. Keep automated tests and user/AWS
feedback inside each piece, not as a final testing phase.

The first seven rows are the dashboard runtime. The rows from `design-system` on are
the design system and app pieces, in dependency order. Each of those is gated by tests
named by ID in [the design-system contract](../../../build-console-product/reference/design-system.md#tests),
[the app kit contract](../../../build-console-product/reference/app-kit.md#tests) or
[the sign-in contract](../../../build-console-product/reference/google-sign-in.md#definition-of-done-for-access-sign-in).
Implement each test as an automated test named by its ID; a piece is done only when
every one of its IDs passes. Check [Status](#status) before relying on any row.

from a Figma design is Enact agent configuration (its tools, repositories and limits),
